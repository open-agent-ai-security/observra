The pipeline

From raw signal to clear insight.

Observra runs a four-stage pipeline on every event your agents emit — automatically, with no custom instrumentation required.

01 · ↓

Collect

Point Observra at your agent runtime — SDK, sidecar, or log forwarder. It ingests events the moment they happen, with sub-millisecond overhead.

02 · ⬡

Normalize

Every event is mapped to Observra's canonical schema — timestamps, agent IDs, event types, tool calls, and outcomes — regardless of which framework emitted it.

03 · ✦

Enrich

Context is added automatically: session graphs, causal chains, policy bindings, and cross-agent correlation. Raw events become meaningful telemetry.

04 · ◎

Observe

Query your enriched signal store, set drift alerts, and route events to your existing observability stack — OpenTelemetry, Grafana, Datadog, and more.

Signal coverage

Everything your agents emit.

Observra captures the full behavioral surface of a running agent — not just logs.

  • 🛠
    Tool invocations Every tool call, argument set, and result — with latency and success/failure status attached.
  • 💬
    LLM turn traces Input tokens, output tokens, model ID, sampling params, and finish reason for every inference call.
  • 🔗
    Session graphs Causal chains across multi-turn conversations and multi-agent handoffs, rendered as queryable graphs.
  • ⚠️
    Anomaly signals Unexpected tool use, unauthorized outbound calls, retry storms, and policy divergence — flagged automatically.
  • 📊
    Resource metrics Cost, latency, and throughput per agent, per session, per tool — aggregated and queryable in real time.

Get started in minutes

Install the Claude Code plugin.

Observra runs as a plugin in your coding agent. No complex setup — add the registry, install, and point it at an agent runtime.

Claude Code · plugin install
# 1 · add the Observra plugin registry
> /plugin marketplace add open-agent-ai-security/observra

# 2 · install the plugin
> /plugin install observra@open-agent-ai-security

# 3 · start collecting telemetry
> Start Observra telemetry collection on ./my-agent
1

Add the registry

Register Observra's plugin marketplace in your Claude Code environment — one command, no configuration files.

2

Install the plugin

The plugin installs locally with no external dependencies. The event renderer is stdlib-only — nothing extra to manage.

3

Point at your agent

Tell Observra which agent runtime to instrument. It auto-discovers the framework and begins streaming telemetry immediately.

4

Read the stream

A live dashboard, machine-readable JSON, and an OpenTelemetry-compatible export land in ./observra/. Nothing leaves your machine.
